# Raynna's Nameplates

Spot your target in a crowd with a gold glow and silver corner pins. Before combat, bar colours distinguish neutral and hostile mobs. During combat, they show when you're gaining threat or have aggro.

- See health values and percentages, casts and channels, and player resources. Class badges can show a specialization when the client provides it.
- See green-bordered buffs above the name and red-bordered debuffs below the bars, with timers beneath the icons. Filter helpful buffs to those your character can apply.
- Portals and other non-combat objects use a compact icon and name label.
- Adjust friendly NPCs, hostile NPCs, friendly players, and enemy players separately. Enable a personal health plate if you want one for yourself.
- Compare four live previews while adjusting scale, colours, and aura size. Settings are searchable and saved per character.

Type **/rnp** to open settings or **/rnp preview** to toggle the previews. You can also left-click the minimap button for previews or right-click it for settings.

Built for **WoW Forever**. Plater is optional.

## Install

Download the ZIP from Releases and extract the RaynnaNameplates folder into your WoW Forever Interface/AddOns folder.
