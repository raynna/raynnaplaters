# Raynna's Nameplates 1.4.38

- New profiles use the author's saved character settings. The personal plate starts enabled at 80% with resource values visible. Live previews start disabled.
- Friendly and enemy player plates support separate surnames, guild placement, resource height and value formats. Both default to guild names in plain text under the character name.
- Choose from six target glow styles. The default is a pale soft glow with 12 px spread and 100% target scale.
- Adjust fonts, wrapping, text sizes, and health and resource number formats in the settings preview.
- Toggle individual personal plate elements. Hiding health collapses the row above the resource bar.
- Harmful debuffs and crowd control share the bottom-left row by default.
